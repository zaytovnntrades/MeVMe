# MeVMe
## Claude Code plugin

This repo is also a personal plugin marketplace. In Claude Code:

```
/plugin marketplace add zaytovnntrades/MeVMe
/plugin install nq-trading@mevme
```

It adds four skills for NQ/MNQ paper trading: `nq-risk` (sizing and the 2R test), `nq-replay-coach`, `nq-pine` and `tvclaude-setup`. See `plugins/nq-trading/README.md`.
